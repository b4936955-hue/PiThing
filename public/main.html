About this library

Pi's digits are conjectured (and, as far as anyone has ever checked, empirically behave as if) normal — every finite digit string should appear somewhere in them, given enough digits, the same way Borges' Library of Babel contains every possible page. This app searches, browses, and renders a source file of pi digits four different ways.

Speed

Letters

Non-overlapping pairs of digits (00 through 99), mod 26, become one letter A-Z — a genuine continuous decode of the whole digit stream, not something computed only for search. If you had something else in mind for the digit-to-letter mapping, it's isolated to pairToLetter() in src/piIndex.js and easy to swap.

Getting more digits

The default source is stuff.mit.edu's 1-billion-digit file. For roughly 100 billion digits without needing ~100GB of disk, this app stores digits packed 9-per-4-bytes (~44GB instead of ~100GB) — run node scripts/build-index.js file1.txt file2.txt ... against downloaded chunk(s) from a larger source (e.g. JA0HXV's 100-billion-digit page, or pi2e.ch's chunked releases) to build it.
